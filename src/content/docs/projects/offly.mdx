**Offly** is a self-hosted time-off manager: a calendar grid per user and per team,
public holidays by country, report export and optional SSO authentication. A single
Docker image, no mandatory external dependency.


| | |
| --- | --- |
| **Role** | Self-hosted time-off manager: calendar, teams, public holidays |
| **Stack** | Go · React · SQLite or MongoDB |
| **License** | see the repository |
| **Image** | `bananaops/offly` |
| **Helm chart** | not published — chart available in `helm/` |
| **Repository** | [BananaOps/offly](https://github.com/BananaOps/offly) · [releases](https://github.com/BananaOps/offly/releases) |

## Features

| Feature | Description |
| --- | --- |
| **Calendar grid** | Monthly view of time off per user and per team |
| **Teams** | Group users into teams and track availability |
| **Absence types** | Full day, morning only, afternoon only |
| **Public holidays** | Managed per country |
| **Quick search** | Instant search across users and teams |
| **Presence view** | Real-time overview of who is in today |
| **Export** | Time-off reports as CSV and PDF |
| **Dark mode** | Full light and dark themes |
| **SSO / OIDC** | Optional authentication through Dex (PKCE flow) |
| **RBAC** | Role-based access control (`admin` / `user`) |

## Tech stack

| Layer | Technology |
| --- | --- |
| Backend | Go 1.26, gRPC, gRPC-Gateway, Protocol Buffers |
| Frontend | React 18, TypeScript 5, Tailwind CSS 3, Vite 8 |
| Database | SQLite (default) · MongoDB (optional) |
| Authentication | Dex (OIDC/PKCE), JWT, JWKS |
| Container | Docker (multi-stage, Alpine) |

<TabItem label="Docker">

  bananaops/offly:latest

## Configuration

| Variable | Description | Default |
| --- | --- | --- |
| `STORAGE_TYPE` | `sqlite` or `mongodb` | `sqlite` |
| `SQLITE_DB_PATH` | SQLite database path | `/app/data/offly.db` |
| `MONGO_URI` | MongoDB connection string | `mongodb://localhost:27017` |
| `HTTP_PORT` | HTTP port | `8080` |
| `GRPC_PORT` | gRPC port | `50051` |
| `AUTH_ENABLED` | Enables SSO authentication | `false` |
| `AUTH_ISSUER_URL` | OIDC issuer URL | — |
| `AUTH_CLIENT_ID` | OIDC client ID | — |

## SSO authentication

Offly accepts an OIDC provider through [Dex](https://dexidp.io), using the PKCE flow:

```
Browser ──PKCE──▶ Dex ──ID Token──▶ Backend ──JWT check──▶ SQLite
```

| Role | Permissions |
| --- | --- |
| `admin` | Full access — users, teams, public holidays, time off |
| `user` | Read everything · edit only their own profile and time off |

The full guide is in [SSO-README.md](https://github.com/BananaOps/offly/blob/main/SSO-README.md).

## API

### REST — port 8080

Interactive documentation at `http://localhost:8080/docs`.

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/api/v1/health` | Health check |
| `GET` / `POST` | `/api/v1/users` | List / create users |
| `GET` `PUT` `DELETE` | `/api/v1/users/{id}` | Read / update / delete a user |
| `GET` / `POST` | `/api/v1/teams` | List / create teams |
| `GET` / `POST` | `/api/v1/absences` | List / create time off |
| `PUT` / `DELETE` | `/api/v1/absences/{id}` | Update / delete time off |
| `GET` / `POST` | `/api/v1/holidays` | List / create public holidays |
| `GET` | `/api/v1/auth/config` | SSO configuration |

### gRPC — port 50051

Exposed services: `AbsenceService`, `UserService`, `OrganizationService`, `HolidayService`.
