**Tracker** is an open source event tracking platform for distributed systems. It
centralises deployments, operations, incidents and configuration drift, keeps an
inventory of your services and coordinates concurrent operations through
distributed locks. Web UI, REST API and gRPC.

## Features

### Event management
- **Multiple types**: deployments, operations, drift, incidents, RPA runs
- **Rich metadata**: priority, status, environment, owner, impact
- **Links**: attach an event to a pull request, a ticket or another event
- **Views**: timeline, monthly calendar, Gantt chart with overlap detection
- **Insights**: event breakdown and trends over a configurable period

### Service catalog
- Inventory of modules, libraries, projects and containers
- Version and owner tracking
- Interactive dependency graph
- Compliance: spot projects that rely on outdated deliverables

### Distributed locks
- Exclusive locks to prevent concurrent operations
- Identified owner, automatic expiry
- Manage and release locks from the UI

### API and integrations
- Native **gRPC** and **REST** through grpc-gateway
- **Swagger UI** and OpenAPI specification
- **MCP server** (Model Context Protocol) for AI agents
- **Prometheus**: built-in metrics endpoint
- **Homer**: sync links from your dashboard

## Prerequisites

- MongoDB 7 (or FerretDB)
- Docker, or Go 1.26+ and Node.js to run from source

## Configuration

### Environment variables

| Variable | Description | Default |
| --- | --- | --- |
| `DB_HOST` | MongoDB host | `127.0.0.1` |
| `DB_PORT` | MongoDB port | `27017` |
| `DB_NAME` | Database name | `tracker` |
| `DB_USERNAME` / `DB_PASSWORD` | MongoDB authentication | — |
| `HTTP_PORT` | HTTP port (UI + REST) | `8080` |
| `GRPC_PORT` | gRPC port | `8765` |
| `LOG_LEVEL` | Log level | `info` |
| `JIRA_DOMAIN` / `JIRA_PROJECT_KEY` | Jira integration for drift | — |
| `SLACK_WORKSPACE` / `SLACK_EVENTS_CHANNEL` | Slack integration | — |
| `HOMER_URL` | Homer dashboard to sync | — |

### Helm values

```yaml
# values.yaml
mongodb:
  enabled: true          # set to false to point at an external database
  auth:
    enabled: false

image:
  repository: bananaops/tracker
  tag: ""                # defaults to the chart appVersion

env:
  db:
    host: tracker-mongodb
    port: 27017
  jira:
    domain: "jira.company.com"
    projectKey: ""
  slack:
    workspace: "your-workspace"
    eventsChannel: ""
  homer:
    url: ""

service:
  type: ClusterIP
  grpc:
    port: 8765
```

```bash
helm install tracker bananaops-tracker/tracker -f values.yaml \
  --namespace tracker --create-namespace
```

## Usage

### Create a deployment event

```bash
curl -X POST http://localhost:8080/api/v1alpha1/event \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Deploy service-api v2.1.0 to production",
    "attributes": {
      "message": "Deployed via GitHub Actions",
      "type": 1,
      "priority": 2,
      "service": "service-api",
      "status": 3,
      "environment": 7,
      "owner": "platform-team"
    },
    "links": {
      "pullRequestLink": "https://github.com/org/repo/pull/123",
      "ticket": "PROJ-456"
    }
  }'
```

The full list of codes (`type`, `priority`, `status`, `environment`) is described
in the OpenAPI specification, served at `/docs`.
